# image-gallery
📄 Description: Interactive Image Gallery with Lightbox Effect
This project is an interactive image gallery built using HTML, CSS, and JavaScript. It features a simple, responsive layout where users can click on any image to view it in an enlarged format (lightbox effect). A close button (X) allows users to dismiss the enlarged image and return to the gallery view.

💡 Key Features:
Thumbnail grid layout for displaying multiple images.

Click-to-enlarge functionality: clicking any image opens it in a larger overlay view.

Close button (X) to exit the full-screen image view.

No external libraries or frameworks used—just pure HTML, CSS, and JavaScript.

This project demonstrates basic DOM manipulation and event handling in JavaScript, as well as the use of overlays and modal design using CSS.
